# NumTick - 자동 슈팅 서바이벌 게임

탕탕특공대 스타일의 모바일 최적화 자동 슈팅 서바이벌 게임입니다.

## 플레이 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 서버 불필요.

### 조작법
- **PC**: WASD 또는 방향키로 이동
- **모바일**: 왼쪽 화면 터치하여 가상 조이스틱으로 이동
- **공격**: 자동 (가장 가까운 적을 자동으로 공격)

## 게임 시스템

### 챕터 & 스테이지
- **3개 챕터**: 수풀 숲, 사막 유적, 화산 지대
- **챕터당 5개 스테이지**, 총 15개 스테이지
- 각 스테이지는 **5웨이브 + 보스전**으로 구성
- 클리어 성과에 따라 **1~3성** 평가

### 상점 (영구 업그레이드)
골드를 모아 영구 스탯을 강화할 수 있습니다:
- 최대 체력, 공격력, 공격 속도, 이동 속도
- 경험치 보너스, 골드 보너스, 시작 레벨

### 인게임 스킬 (레벨업 시 선택)
| 스킬 | 최대 Lv | 설명 |
|------|---------|------|
| 멀티샷 | 5 | 투사체 수 증가 |
| 공격 속도 | 5 | 공격 속도 증가 |
| 공격력 강화 | 5 | 데미지 증가 |
| 관통 | 3 | 투사체가 적을 관통 |
| 회전 구체 | 5 | 주변 회전 구체 소환 |
| HP 재생 | 5 | 초당 HP 회복 |
| 최대 HP | 5 | 최대 HP 증가 |
| 이동 속도 | 3 | 이동 속도 증가 |
| 유도탄 | 3 | 투사체가 적 추적 |
| 체인 라이트닝 | 5 | 주기적 번개 발사 |
| 폭발탄 | 3 | 범위 폭발 |
| 경험치 자석 | 3 | 흡수 범위 증가 |

### 적 종류
- **졸개**: 기본 적
- **돌격병**: 빠르지만 약함
- **탱커**: 느리고 강함
- **사격병**: 원거리 공격
- **벌레**: 약하지만 대량 출현
- **폭탄병**: 근접 시 폭발

## 기술 스택
- HTML5 Canvas
- Vanilla JavaScript
- CSS3
- LocalStorage (세이브)
- 모바일 터치 지원 (가상 조이스틱)
