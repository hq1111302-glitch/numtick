# NumTick - 자동 슈팅 서바이벌 게임

탕탕특공대 스타일의 브라우저 기반 자동 슈팅 서바이벌 게임입니다.

## 플레이 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

### 조작법
- **이동**: WASD 또는 방향키
- **공격**: 자동 (가장 가까운 적을 자동으로 공격)

### 게임 규칙
- 몰려오는 적들을 물리치고 경험치를 모아 레벨업하세요
- 레벨업할 때마다 3가지 스킬 중 하나를 선택할 수 있습니다
- 각 스테이지 끝에는 보스가 출현합니다
- 최대한 오래 생존하세요!

## 스킬 목록
| 스킬 | 최대 레벨 | 설명 |
|------|----------|------|
| 멀티샷 | 5 | 투사체 수 증가 |
| 공격 속도 | 5 | 공격 속도 증가 |
| 공격력 강화 | 5 | 데미지 증가 |
| 관통 | 3 | 투사체가 적을 관통 |
| 회전 구체 | 5 | 주변을 회전하는 구체 소환 |
| HP 재생 | 5 | 초당 HP 회복 |
| 최대 HP | 5 | 최대 HP 증가 |
| 이동 속도 | 3 | 이동 속도 증가 |
| 유도탄 | 3 | 투사체가 적을 추적 |
| 체인 라이트닝 | 5 | 주기적으로 번개 발사 |
| 폭발탄 | 3 | 투사체 명중 시 범위 폭발 |
| 경험치 자석 | 3 | 경험치 흡수 범위 증가 |

## 적 종류
- **졸개**: 기본 적
- **돌격병**: 빠르지만 체력이 낮음
- **탱커**: 느리지만 체력이 높음
- **사격병**: 원거리에서 투사체 공격
- **벌레**: 약하지만 많이 출현
- **폭탄병**: 근접 시 폭발

## 기술 스택
- HTML5 Canvas
- Vanilla JavaScript (프레임워크 없음)
- CSS3
